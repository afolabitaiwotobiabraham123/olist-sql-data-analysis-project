# Brazilian Olist E-Commerce Data Analysis

## 📊 Project Overview

This project is an end-to-end data analytics project focused on exploring and analyzing the Brazilian Olist E-Commerce dataset. The goal is to transform raw e-commerce data into meaningful business insights that can help understand sales performance, customer behavior, product performance, payment methods, order fulfillment, delivery efficiency, and customer satisfaction.

The project follows a structured data analytics workflow, beginning with data exploration and quality assessment, followed by data cleaning and preparation, relational database analysis, exploratory data analysis, business-focused SQL queries, data visualization, and the development of interactive dashboards.

The analysis combines multiple tools and technologies to demonstrate practical data analyst skills across the full analytics process.

## 🎯 Project Objectives

The key objectives of this project are to:

* Explore and understand the structure and relationships within the Olist e-commerce database.
* Perform data quality assessments across the available datasets.
* Identify missing values, duplicate records, inconsistent data, and other potential data quality issues.
* Understand primary keys, foreign keys, and relationships between the different tables.
* Clean and prepare the data for reliable analysis.
* Use SQL to query and analyze relational e-commerce data.
* Use Python and Pandas for data manipulation, exploratory data analysis, and additional analytical tasks.
* Investigate sales and revenue performance.
* Analyze customer purchasing behavior and geographic patterns.
* Examine product performance and category trends.
* Analyze payment methods and payment behavior.
* Evaluate order delivery and fulfillment performance.
* Explore customer review scores and their relationship with the overall customer experience.
* Create meaningful data visualizations to communicate key findings.
* Develop an interactive Power BI dashboard to present business insights.
* Translate analytical findings into clear, data-driven business recommendations.

## 🔍 Project Workflow

The project follows these major stages:

### 1. Data Understanding & Exploration

* Explore the available Olist datasets.
* Understand the purpose and structure of each table.
* Examine the number of rows and columns.
* Identify important fields and data types.
* Understand relationships between tables.

### 2. Data Quality Assessment

* Check for NULL and missing values.
* Identify duplicate records.
* Investigate unique and non-unique values.
* Validate potential primary keys.
* Identify foreign key relationships.
* Check for inconsistencies and potential data quality issues.

### 3. Data Cleaning & Preparation

* Handle missing or incomplete data where appropriate.
* Remove or investigate duplicate records.
* Standardize and transform data where necessary.
* Prepare datasets for analysis.

### 4. SQL Analysis

Use SQL to answer business questions and generate insights related to:

* Sales and revenue performance.
* Customer behavior.
* Product and category performance.
* Seller performance.
* Payment methods.
* Order volume.
* Delivery performance.
* Customer reviews and satisfaction.

### 5. Python Data Analysis

Use Python and Pandas to:

* Perform additional data cleaning and transformation.
* Conduct exploratory data analysis.
* Analyze trends and distributions.
* Create visualizations.
* Identify patterns and relationships within the data.

### 6. Data Visualization & Dashboarding

Create clear and interactive visualizations using:

* Matplotlib
* Seaborn
* Power BI

Develop an interactive dashboard that communicates key business metrics, trends, and insights.

### 7. Insights & Recommendations

Summarize the most important findings from the analysis and provide data-driven recommendations based on the results.
